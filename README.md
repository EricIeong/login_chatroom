# 💬 Real-Time Chatroom with Login & Database

A full-stack web application that allows users to create accounts, log in, and exchange messages in real time.  
Built as part of a web development course and extended with custom features.

## 🔧 Tech Stack
- **Frontend**: HTML, CSS, JavaScript (Vanilla)
- **Backend**: PHP
- **Database**: MySQL (hosted locally or via cloud)
- **Authentication**: Session-based
- **Version Control**: Git & GitHub

## ✨ Features
- User registration and login
- 1 hour message history stored in MySQL
- Real-time message updates
- Simple, responsive chat interface
- Session management (stay logged in)
